# C++ GPA Calculator

A console-based GPA calculator developed in C++.

## Features

- Supports two different grading systems
- Calculates GPA based on course credits
- Accepts lowercase and uppercase letter grades
- Validates invalid letter grade inputs
- Displays course information in a formatted table
- Uses functions and arrays for program organization

## Concepts Used

- Functions
- Arrays
- Loops
- If / else statements
- Input validation
- String manipulation
- iomanip
